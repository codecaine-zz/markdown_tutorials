## Basic Navigation Shortcuts

### Core Windows 11 Navigation
```powershell
# Open or close Start Menu
Win

# Open Quick Settings panel (Wi-Fi, Bluetooth, Airplane Mode, Volume, Brightness)
Win + A

# Open Notification Center and Calendar tray
Win + N

# Open File Explorer
Win + E

# Open Settings app
Win + I

# Open Run dialog box (Launch executables, shell shortcuts, regedit)
Win + R

# Open Task View (Virtual desktop manager and timeline)
Win + Tab

# Open Search flyout
Win + S  (or Win + Q)

# Open Widgets board
Win + W

# Open Quick Link / Power User menu (Start button right-click menu)
Win + X

# Show or hide desktop (Minimizes all windows instantly)
Win + D
```

## Window Snapping & Layout Management

Windows 11 introduces native **Snap Layouts** and enhanced keyboard snapping actions:

### Snap Layouts & Tiling
```powershell
# Open Snap Layouts menu on active window
Win + Z

# Snap active window to Left Half of screen
Win + Left Arrow

# Snap active window to Right Half of screen
Win + Right Arrow

# Maximize active window (or snap to Top Quarter after left/right snap)
Win + Up Arrow

# Restore / Minimize active window
Win + Down Arrow

# Snap to Four Corners (Quadrants)
Win + Left Arrow -> then Win + Up Arrow   # Top-Left quadrant
Win + Left Arrow -> then Win + Down Arrow # Bottom-Left quadrant
Win + Right Arrow -> then Win + Up Arrow  # Top-Right quadrant
Win + Right Arrow -> then Win + Down Arrow # Bottom-Right quadrant

# Aero Shake: Minimize all background windows EXCEPT active one
Win + Home

# Move active window across multiple monitors
Win + Shift + Left Arrow   # Move to monitor on left
Win + Shift + Right Arrow  # Move to monitor on right

# Switch between active windows across current desktop
Alt + Tab

# Switch between windows of same app (with modern Taskbar grouping)
Ctrl + Click app icon on Taskbar
```

## File Explorer Shortcuts

Windows 11 File Explorer features native tabs, a streamlined command bar, and modern context menus:

### Navigation & Tabs
```powershell
# Open a new tab in current File Explorer window
Ctrl + T

# Close current tab
Ctrl + W

# Switch to next tab
Ctrl + Tab

# Switch to previous tab
Ctrl + Shift + Tab

# Open a new File Explorer window
Ctrl + N

# Focus Address / Location bar (Type path or launch cmd/powershell in directory)
Ctrl + L  (or Alt + D)

# Focus Search box
Ctrl + F  (or Ctrl + E)

# Navigate to Parent folder
Alt + Up Arrow

# Navigate Back in history
Alt + Left Arrow  (or Backspace)

# Navigate Forward
Alt + Right Arrow
```

### File Operations
```powershell
# Create a new folder
Ctrl + Shift + N

# Rename selected item
F2

# Open Properties dialog for selected item
Alt + Enter

# Delete selected item (Move to Recycle Bin)
Delete

# Permanently delete selected item (Bypasses Recycle Bin)
Shift + Delete

# Copy full file path to clipboard (Windows 11 feature)
Ctrl + Shift + C

# Show Classic Windows Context Menu (Bypasses compact menu)
Shift + F10

# Toggle Preview Pane on/off
Alt + P

# Toggle Details Pane on/off
Alt + Shift + P
```

### Security & Hardware
```powershell

Win + L

# Open Task Manager directly (Bypasses login screen)
Ctrl + Shift + Esc

Win + Ctrl + Shift + B

Win + P

# Open Game Bar (FPS counters, audio mixer, capture)
Win + G
```

```powershell

Win + Shift + S

# Capture entire screen and save directly to %USERPROFILE%\Pictures\Screenshots
Win + PrintScreen

# Capture active window only to clipboard
Alt + PrintScreen

# Record screen using Xbox Game Bar
Win + Alt + R
```

## Windows Terminal Shortcuts

Windows Terminal is the standard default terminal emulator on Windows 11:

```powershell
# Open a new tab (default profile)
Ctrl + Shift + T

# Open a new tab with specific profile number (1 to 9)
Ctrl + Shift + 1..9

# Close current active tab
Ctrl + Shift + W

# Switch to next tab
Ctrl + Tab

# Switch to previous tab
Ctrl + Shift + Tab

# Split active pane Vertically
Alt + Shift + Plus (+)

# Split active pane Horizontally
Alt + Shift + Minus (-)

# Move focus between split panes
Alt + Arrow Keys

# Resize focused split pane
Alt + Shift + Arrow Keys

# Close focused split pane
Ctrl + Shift + W

# Open Find / Search dialog in terminal buffer
Ctrl + Shift + F

# Open Command Palette (Search all terminal actions and settings)
Ctrl + Shift + P

# Zoom in / Zoom out terminal font size
Ctrl + Plus (+) / Ctrl + Minus (-)
Ctrl + 0  # Reset zoom to default
```

### Custom Hotkey Remapping with PowerToys
If you need custom key bindings or want to map macOS Command-style shortcuts (`Ctrl` to `Alt`):
1. Install PowerToys: `winget install Microsoft.PowerToys -e`
2. Open PowerToys Settings -> **Keyboard Manager**.
3. Use **Remap a key** or **Remap a shortcut** to configure global or per-application shortcuts.
